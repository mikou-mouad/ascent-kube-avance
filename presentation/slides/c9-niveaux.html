Chapitre 9 · Le concept

Une politique : la première règle gagne

None

rien : les sondes, les events, le bruit

Metadata

qui, quoi, quand, sans le contenu

Request

+ le corps de la requête

RequestResponse

+ la réponse : tout, mais volumineux

Les Secrets : jamais au-delà de Metadata, sinon les mots de passe finissent dans le journal.

apiVersion: audit.k8s.io/v1
kind: Policy
rules:
# 1. le bruit
- level: None
  resources: [{resources: [events]}]
# 2. secrets : qui, jamais quoi
- level: Metadata
  resources: [{resources: [secrets]}]
# 3. les lectures
- level: None
  verbs: [get, list, watch]
# 4. modifs dans croustino
- level: RequestResponse
  namespaces: [croustino]
- level: Metadata

L'ordre compte : la règle des Secrets est avant celle des lectures, sinon la lecture d'un Secret ne serait jamais tracée. La politique complète est dans k8s/audit/audit-policy.yaml.
