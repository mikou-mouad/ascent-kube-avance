DNS STABLE (Service headless)

postgres-0.postgres.croustino.svc

kind: StatefulSet
metadata: {name: postgres}
spec:
  serviceName: postgres # headless
  template:
    spec:
      containers:
      - name: postgres
        volumeMounts:
        - name: data
          mountPath: /var/lib/postgresql/data
  volumeClaimTemplates:
  - metadata: {name: data}
    spec:
      resources: {requests: {storage: 1Gi}}

Le PVC créé s'appelle data-postgres-0 : nom du template, nom du StatefulSet, numéro du pod. Attention : 2 réplicas = 2 bases indépendantes, pas de réplication. Pour ça, il faut un opérateur (CloudNativePG).
