L'API server est un static pod : on l'active en modifiant /etc/kubernetes/manifests/kube-apiserver.yaml, et le kubelet le redémarre seul.

Toujours sauvegarder kube-apiserver.yaml HORS du dossier manifests : une copie dedans serait lancée comme un second API server.
