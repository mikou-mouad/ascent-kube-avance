Branche tp-NN = l'application au début du TP NN, son énoncé et sa correction.

La correction est dans solutions/, sans rien du TP suivant.

Bloqué ? On consulte la correction, ou on repart de la branche suivante.

# TP 02, sur le control plane
git clone https://github.com/
  mikou-mouad/ascent-kube-avance.git
  ~/croustino

# début de chaque TP suivant
cd ~/croustino && git fetch
git stash -u
git checkout tp-03-stockage

Montrer le dépôt sur GitHub. Les dossiers : app/ (le code), k8s/ (les manifests), helm/ (à partir du TP 06), tp/ (les énoncés), solutions/NN-*/ (la correction de chaque TP : fichiers corrigés et réponses aux questions). La correction est volontairement accessible : chacun avance à son rythme.
