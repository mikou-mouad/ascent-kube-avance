Chapitre 10 · Le concept

Brancher le cluster sur Harbor

1. Copier les images (skopeo)

skopeo copy \
  --dest-creds "$ROBOT:$SECRET" \
  docker://ghcr.io/…/croustino-back:1.0 \
  docker://10.10.0.10:30002/croustino/…

2. Faire confiance au registre (3 nœuds)

# /etc/containerd/certs.d/
#  10.10.0.10:30002/hosts.toml
server = "http://10.10.0.10:30002"
[host."http://10.10.0.10:30002"]
  capabilities = ["pull", "resolve"]

3. S'authentifier avec le robot

kubectl create secret docker-registry \
  harbor-croustino -n croustino \
  --docker-server=10.10.0.10:30002 \
  --docker-username="$ROBOT" \
  --docker-password="$SECRET"

4. Pointer le chart vers Harbor

# values-rennes.yaml
imageRegistry: 10.10.0.10:30002/croustino
imagePullSecrets:
  - name: harbor-croustino

Harbor est exposé en HTTP pour la formation : d'où la configuration explicite de containerd. En production : TLS avec un vrai certificat, et plus besoin de hosts.toml. Les valeurs imageRegistry et imagePullSecrets existent dans le chart depuis le TP 06.
