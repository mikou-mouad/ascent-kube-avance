Le back en YAML : les labels font le lien

kind: Deployment
metadata: {name: back}
spec:
  replicas: 2
  selector:
    matchLabels: {app: back}
  template:
    metadata:
      labels: {app: back}
    spec:
      containers:
      - name: back
        image: …/croustino-back:1.0
        envFrom:
        - configMapRef: {name: back-config}

kind: Service
metadata: {name: back}
spec:
  selector: {app: back}
  ports:
  - port: 8080
    targetPort: http

kind: ConfigMap
metadata: {name: back-config}
data:
  DB_HOST: postgres
  STOCK_MAX: "24"

Le selector du Deployment doit correspondre aux labels du template. Le Service utilise les mêmes labels. DB_HOST vaut « postgres » : c'est le nom du Service de la base, résolu par le DNS du cluster.
