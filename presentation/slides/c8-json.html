Chapitre 8 · Le concept

Logs JSON : une info, un champ

Ce que le back écrit sur stdout :

{"niveau": "ERROR", "evenement": "commande_rejetee", "commande_id": "1268863b",
 "client": "Mme Lebrun", "quantite": 30, "raison": "fournée insuffisante (max 24)"}

Ce que Fluent Bit ajoute :

"kubernetes": {
  "namespace_name": "croustino",
  "pod_name": "back-7d9f-x2k",
  "node": "worker2" … }

Ce qu'on tape dans Kibana (KQL) :

kubernetes.namespace_name : "croustino"
and client : "Mme Lebrun"
and niveau : "ERROR"

Réponse en 2 secondes : commande 1268863b, 30 croissants, rejetée car la fournée est limitée à 24. Le pod n'existe plus, la trace oui.

Avec du texte libre, il faudrait des expressions régulières fragiles. En JSON, le filtre kubernetes de Fluent Bit (Merge_Log On) transforme chaque clé en champ interrogeable.
