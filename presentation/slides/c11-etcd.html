Sauvegarder et restaurer etcd

snapshot save

photo de tout le cluster

l'accident

namespace supprimé

snapshot restore

dans un nouveau dossier

etcd.yaml

pointe vers ce dossier

# sauvegarde (etcdctl est dans le pod etcd)
kubectl -n kube-system exec etcd-controlplane -- etcdctl --endpoints=https://127.0.0.1:2379 \
  --cacert=/etc/kubernetes/pki/etcd/ca.crt --cert=…/server.crt --key=…/server.key \
  snapshot save /var/lib/etcd/sauvegarde-tp11.db
# restauration dans un nouveau dossier
kubectl -n kube-system exec etcd-controlplane -- etcdutl snapshot restore \
  /var/lib/etcd/sauvegarde-tp11.db --data-dir /var/lib/etcd/restauration …
# puis dans /etc/kubernetes/manifests/etcd.yaml : hostPath → /var/lib/etcd/restauration

Une restauration ramène tout le cluster en arrière : à réserver aux catastrophes. Pour un namespace, on redéploie depuis Git et Helm.

La sauvegarde doit partir hors du control plane (stockage objet, autre site) et être testée. Velero est l'outil de référence pour sauvegarder des namespaces et leurs volumes.
