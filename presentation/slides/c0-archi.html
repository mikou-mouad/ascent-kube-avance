Le réseau entre les pods de tous les nœuds est fourni par le CNI (chez nous : Calico).

Tout passe par l'API server : kubectl, le scheduler, le kubelet. Seul l'API server parle à etcd. Le kubelet est l'agent sur chaque nœud : il demande à containerd de lancer les conteneurs.
