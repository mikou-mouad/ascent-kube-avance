Chapitre 6 · Le concept

Un template + des values = du YAML

helm/croustino/
├─ Chart.yaml
├─ values.yaml
├─ values-rennes.yaml
├─ values-lyon.yaml
└─ templates/
   ├─ _helpers.tpl
   ├─ configmap.yaml
   ├─ postgres.yaml
   ├─ back.yaml
   └─ front.yaml

# templates/back.yaml
kind: Deployment
metadata: {name: back}
spec:
  replicas: {{ .Values.back.replicas }}
    image: {{ .Values.imageRegistry }}/…

# values-lyon.yaml
ville: Lyon
stockMax: 12
back:
  replicas: 1
front:
  nodePort: 30081

Tester le rendu sans rien installer :

helm template croustino \
  helm/croustino \
  -f values-lyon.yaml

values.yaml contient les valeurs par défaut, chaque fichier de ville ne surcharge que ce qui change. Le namespace n'est jamais écrit en dur : {{ .Release.Namespace }}. helm lint détecte les erreurs de syntaxe.
